01 · Project Overview

What is SmartAttend Pro?

SmartAttend Pro is a comprehensive employee monitoring platform that combines biometric face recognition, AI-driven productivity analytics, geolocation verification, and real-time dashboards into a single unified system. It eliminates manual attendance processes and gives organisations deep visibility into workforce performance.

Core System Goals

1
Identity Verification

Identify employees using AI-powered face recognition — no cards or PINs needed.

2
Auto Attendance

Mark check-in and check-out automatically as soon as a face is verified.

3
Productivity Analysis

Track active work time, idle periods, apps used and calculate productivity scores.

4
Remote Monitoring

Monitor remote workers with screenshots, webcam checks, and GPS verification.

5
AI Predictions

Predict employee performance, burnout risk, and attrition using ML models.

6
Admin Dashboard

Centralised real-time dashboard for admins to monitor the entire workforce.

Why JWT? JSON Web Tokens are stateless — they carry the user's role and ID inside an encrypted payload, so the server doesn't need to maintain session state. Every subsequent API request includes this token in the Authorization header for validation.

M02

Face Recognition Module

Core AI Feature · Webcam · Embeddings · Identity matching

Purpose: This is the heart of the system. Instead of swipe cards or PINs, employees are identified purely by their face. The module uses machine learning to extract unique numerical representations (embeddings) from a face and compares them against stored values.

Step-by-Step: How Face Recognition Works

What are Face Embeddings? Every human face can be converted into a unique 128-dimensional numerical vector using a deep neural network. For example: [0.23, 0.91, -0.44, 0.66, ...]. No two people produce identical vectors. The system stores these at registration and compares them at check-in.

1
REGISTER: Employee uploads face → FaceNet extracts 128D embeddings → stored in DB
2
DETECT: Webcam activates → OpenCV detects face in frame
3
ENCODE: Detected face → FaceNet generates real-time embeddings
4
MATCH: Current embeddings compared against all stored embeddings in DB
5
DECIDE: Cosine similarity score calculated — if > threshold → MATCH
6
RECORD: Attendance saved with employeeId, timestamp, GPS, device info

Attendance Record Saved

employeeId : ObjectId // Reference to user

date : String // "YYYY-MM-DD"
location : GeoPoint // { lat, lng }
deviceInfo : String // Browser / OS

M05

AI Behaviour Monitoring Module

Anomaly detection · Burnout alerts · Suspicious activity

Purpose: Uses machine learning to detect unusual patterns in employee behaviour — such as declining productivity (burnout risk), repeated failed face matches (proxy fraud), or sudden behavioural anomalies.

Burnout Detection: If an employee's productivity score drops consistently over several days, the AI flags a burnout risk and notifies the admin before it becomes a serious problem.

Fake Attendance: If multiple consecutive face match failures are detected for the same employee slot, the system triggers an anomaly alert to the admin.

M06

Geo-Location Module

GPS · Office radius · Remote location validation

Purpose: Verifies that an employee is physically present at an approved location — the office, a client site, or an approved remote address — before accepting their attendance.

1
Employee opens attendance page → browser requests GPS permission
2
GPS coordinates (latitude, longitude) captured
3
Euclidean distance calculated from office coordinates
4
If distance ≤ office radius OR approved remote → ACCEPT
5
If outside all approved zones → REJECT attendance + alert

Distance Formula

d = √( (x₂ − x₁)² + (y₂ − y₁)² )

This module is especially critical for hybrid and fully remote teams. Admin can configure multiple approved locations (home addresses, co-working spaces) per employee through the admin panel.
